# Tab List Animation

A simple but customisable mod that gives the tab list a little more motion instead of the borning vanilla on/off!


</div>

<div align="center">

![All six animation presets opening the tab list at the same time](https://iili.io/nEkgIaf.gif)

</div>

## Features
- Separate open and close animations, each with its own duration and easing
- 31 easings to pick from, or a custom bezier curve
- Scale, slide, fade and row cascade effects that can all be combined
- Toggle tab list option
- 7 presets if you don't want to set everything up yourself
- A config screen with a live preview of every option

## Presets
If you just want something that looks nice, the **Presets** tab has a few ready made setups. Applying one replaces your current settings, and you can tweak it from there.

<div align="center">

| Preset | What it does |
| --- | --- |
| **Default** | Scales the list up from nothing |
| **Vanilla** | No animation at all |
| **Pop** | Scales up from 60% with a small overshoot and a fade |
| **Slide Down** | Slides down from above while fading in |
| **Unfold** | Stretches the list open downwards |
| **Cascade** | Brings the rows in one by one from the left |
| **Bouncy** | Drops the list in from the top and bounces it into place |

</div>

## Requirements
- Minecraft 1.20.1 with [Fabric](https://fabricmc.net/)
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [TimelessLib](https://modrinth.com/mod/timelesslib) 2.0.1 or newer
- [YACL](https://modrinth.com/mod/yacl)
- [Mod Menu](https://modrinth.com/mod/modmenu) (optional, for opening the config in game)

Client side only, so it works on any server without the server needing it.
